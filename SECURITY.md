# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting form rather than a public
issue: <https://github.com/0xRuAI/honest-backtester/security/advisories/new>.

Include the affected version, a minimal reproduction, and the impact. Do not
include live exchange credentials or account data. You should receive an
acknowledgement within seven days.

## Scope

This repository is an offline research library. It does not place orders or
require API keys. Security reports involving dependency supply chains, unsafe
file handling, or a path from public data to code execution are in scope.
Trading-strategy performance and ordinary model limitations are not security
vulnerabilities; please report those as regular issues.
